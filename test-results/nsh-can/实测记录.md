# NSH/CAN 实测记录

测试使用 OK8MP Cortex-M7、P29 CAN1、CAN 收发器模块和 ESP32-S3 模拟 ECU。FlexCAN1 和 ESP32 TWAI 的位速率均为 500 kbit/s。

| 测试项 | NSH 命令或操作 | 实测结果 |
| --- | --- | --- |
| 设备与服务 | `ls /dev/can0`、`can_service start`、`can_service recover` | `/dev/can0` 可用；服务启动并恢复成功。 |
| 控制器健康状态 | `can_service status`、`can_service health` | 控制器处于 `error_active`，错误计数为 0。 |
| 周期报文监测 | ESP32 输入 `t`，M7 执行 `can_monitor start` | 接收 `0x180`，状态为 `healthy`。 |
| 周期、序号和超时检查 | ESP32 分别输入 `p`、`j`、`r` | M7 分别报告 `period_error`、`counter_error` 和 `timeout`；恢复周期发送后回到 `healthy`。 |
| 主动链路诊断 | `can_diagnostic` | M7 发出 `0x700 A5 01 5A`，ESP32 返回 `0x708 5A 01 5A 01`，JSON 结果为 `"ok":true`。 |
| 断线与恢复 | 断开双绞线后执行 `can_diagnostic`，恢复接线后执行 `can_service recover` | 断线时诊断约 1 秒超时；恢复接线和服务恢复后诊断成功。 |
| ISO-TP | `can_ecu isotp-test` | 完成 32 字节 UDS RoutineControl 请求和响应的多帧传输。 |
| UDS 状态与 DTC | `can_ecu status`、`can_ecu set overtemp`、`can_ecu dtc` | 正常状态读取 60 ℃、12600 mV；过热状态读取 P0217。 |
| 低电压 DTC | `can_ecu set low_voltage`、`can_ecu dtc` | 状态切换为低电压，读取 P0562。 |
| DTC 清除 | `can_ecu set normal`、`can_ecu dtc clear`、`can_ecu dtc` | 清除后 DTC 列表为空。 |
| OBD-II | `can_ecu obd supported/coolant/voltage/dtc/vin` | 可查询支持 PID、冷却液温度、电池电压、故障码和 VIN；清除 DTC 后 Mode 03 返回空列表。 |

ESP32 串口在主动诊断时记录：

```text
RX id=0x700 dlc=3 data=A5 01 5A
DIAG response id=0x708 data=5A 01 5A 01 result=0
```

ISO-TP 多帧测试的 NSH 返回包含：

```text
can_ecu: UDS RoutineControl ISO-TP multi-frame verified
{"ok":true,"protocol":"uds-isotp","request_bytes":32}
```
