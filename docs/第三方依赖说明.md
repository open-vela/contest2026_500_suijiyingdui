# 第三方依赖说明

## 开源基础

- Apache NuttX：内核、设备模型、网络协议栈与基础 BSP 框架，Apache License 2.0。
- openvela：uORB、AI Agent 及嵌入式应用框架；本项目基于其公开源码进行 OK8MP 平台适配。
- Mbed TLS：TLS 1.2、X.509 证书链和主机名校验能力，随 openvela/NuttX 构建配置启用。

## 测试与主机工具

- CMocka 1.1.5：XTS 相关单元与驱动测试。
- NIST STS 2.1.2：随机性统计测试。
- Python `pyserial`：Mac 主机执行 UART CMocka 和 YMODEM 测试脚本时使用。

## 硬件资料

- NXP i.MX8M Plus 参考手册与 SDK：时钟、IOMUX、ENET/FEC、I2C、WDOG 和内存控制器寄存器定义参考。
- Forlinx OK8MP 硬件资料：板级引脚、PHY、启动介质与外设连接参考。
- Motorcomm YT8521 数据资料：RGMII/MDIO PHY 初始化与自动协商参考。

## 运行时服务

DeepSeek 仅作为可替换的 OpenAI 兼容 LLM 后端。API Key 不随仓库、镜像或文档提交；演示时由设备侧 `set_llm` 命令临时设置。网络访问通过 M7 自身 TCP/IP 与严格 TLS/X.509 校验完成。
