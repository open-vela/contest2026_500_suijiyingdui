# 源码集成说明

大赛工作区的 `nuttx`、`apps` 和 `packages` 是公共项目。本队仓只保存自主新增的板级目录、应用覆盖代码和端口快照，并通过 manifest 的 `linkfile` 映射到 openvela 工作区。这样可以让评审查看本队提交内容，也避免直接把改动写入公共仓库。

| 本仓路径 | openvela 工作区位置 | 内容 |
| --- | --- | --- |
| `board/ok8mp_m7_openvela/` | `vendor/openvela/boards/contest2026_500_ok8mp_m7_openvela/` | 板级目录、配置、链接脚本、启动、I2C、FEC 和 FlexCAN。 |
| `board/ok8mp_m7_openvela/port_snapshot/nuttx/arch/arm/src/mx8mp/` | `nuttx/arch/arm/src/mx8mp/` | i.MX8MP Cortex-M7 芯片端口快照。 |
| `app/ok8mp_m7_services/overlays/apps/` | `apps/` | 语音、网络、CAN service、CAN monitor、CAN diagnostic 和 ECU 应用。 |
| `app/ok8mp_m7_services/overlays/packages/ai_agent/` | `packages/ai_agent/` | 语音和网络 Tool、Skill 及项目 Agent 覆盖代码。 |

从源码重建时，先完成 `repo sync`，再根据上表将 `port_snapshot` 和 `overlays` 按原始相对路径合入完整工作树。随后选择 `vendor/openvela/boards/contest2026_500_ok8mp_m7_openvela/configs/nsh` 或 `nsh-agent` 配置，并在工作区根目录使用 `build.sh` 构建。主机需要 GNU Arm Embedded Toolchain、GNU Make、Python 3 和 NuttX 的 kconfig 工具。

`firmware/nuttx-ok8mp-m7-can-uds-obd-tested.bin` 是直接 CAN 功能的实板验证镜像。它覆盖 `/dev/can0`、链路诊断、状态监测、ISO-TP、UDS 和 OBD-II；其校验和记录于 `firmware/SHA256SUMS`。本仓中的 Agent 覆盖代码作为源码提交，未通过实板回归的 Agent CAN 机制不作为本次验收结论。
