# 演示视频

**文件名称：** 随机应队《基于 openvela 的新平台适配与 AI Agent 智能应用开发》演示视频

**百度网盘链接：** [https://pan.baidu.com/s/1An33r518zOHb4_BQlM8bHQ?pwd=1yia](https://pan.baidu.com/s/1An33r518zOHb4_BQlM8bHQ?pwd=1yia)
**提取码：** `1yia`

本演示在飞凌 OK8MP 的 Cortex-M7 实际硬件上运行 openvela AI Agent。首先，用户通过自然语言要求 Agent 检查离线语音模块并将指示灯设置为紫色。Agent 调用 `voice_status` 读取 I2C 语音模块的真实版本、忙闲状态和词条数量，再调用 `set_voice_rgb` 控制实体 RGB 灯变为紫色，证明云端 LLM 的推理结果能够转化为 M7 上的真实硬件操作。

随后，Agent 调用 `wait_voice_command` 等待由 `voice_uorb` 发布的离线语音事件。用户说出固定词条后，语音模块在本地完成识别，M7 通过 I2C 读取结果并经 uORB 消息总线传递给 Agent。收到语音事件后，Agent 自动调用 `network_health_check`，在 M7 侧检查 DNS、TLS/X.509 证书校验和 HTTPS 通信状态。网络链路正常时，Agent 将 RGB 灯切换为绿色；若检查失败，则切换红灯并启动蜂鸣器告警。

该演示完整体现了“自然语言任务—Agent 多步 Tool 调用—离线语音事件—M7 网络诊断—实体声光反馈”的闭环，也验证了 I2C 外设驱动、uORB、AI Agent、TLS 安全通信和硬件控制能够在 OK8MP Cortex-M7 平台协同运行。
